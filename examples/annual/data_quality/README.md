## 文件与分母

`quality_by_carpark.csv` 按停车场列出 annual、train、validation、test 和 embargo。`quality_by_split.csv` 给出相同分组的总体统计。annual 是全年总计，不应与其他四组相加。其余四组互斥且覆盖全年，行数为 168,176 / 56,048 / 56,064 / 32。

训练截止 2026-06-11 23:15，验证为 2026-06-12 00:00 至 2026-08-23 23:15，测试从 2026-08-24 00:00 开始。两个边界前的 23:30 和 23:45 归入 embargo。这是按当前快照时点的划分，统计的是原始观测质量，不是未来标签的可训练样本数；因此分母与预测或推荐评估不同。

`rows_valid_5min` 是事件率的分母。所有 `fraction` 列均为 0–1 比例，展示为百分比时乘 100。满位为空位 = 0；低余位为空位 < 3；近满为空位 < 容量的 10%，均包含真正满位。`mean_occupancy_valid` 是逐停车场快照的算术平均，不是按总容量加权的总体占用率。`capacity_distinct_valid` 在分场表表示单场容量种类，在总体表表示该组全部停车场的容量种类。

## 发现

1. 全年满位 18,137 次，其中容量仅 26 的 KAS 贡献 14,293 次（78.81%）。测试期有效快照满位 3,436 次，其中 KAS 3,039 次（88.45%）。应保留按场结果，不能仅用总体平均评价风险。
2. 最近目的地的 KAM 在测试期无满位；CSM、EPM、PRM 测试期也无满位。推荐首选零失败不能证明各策略等效，也不能证明预测推荐减少停车失败。
3. 测试期没有公共假日，无法据此验证假日特征的假日收益。源文件全年有 12 个标记为假日的日期，训练 10 个、验证 2 个。
4. 无效记录有 822 行集中在 2026-03-07 至 03-11，占全部无效记录 46.63%；单日最多的是 03-08（384 行），其次为 10-24（185 行）、03-09（150 行）、06-18（120 行）。缺失的时间聚集性应保留在分段处理与回放分母里。
5. PRM 的正常容量为 576，2026-04-20 14:30、14:45、15:00 三行报告容量 234，对应空位 0、233、232，源表仍标为有效。`anomalies.csv` 保留三条原记录及来源相对路径。它们属于待核实上报变动，本次没有删除、替换或认定为错误。其余七场全年容量恒定。

## 数据出处与解释边界

CSV 的 `source_path` 提供了原始快照的相对文件名，本次未取得或核查这些 JSON 压缩文件、API 响应与采集日志。仅凭 CSV 的内部一致性，不能独立证明整年记录真实来自官方接口，也不能确认采集、补档或转换过程。正式报告的数据出处应由原始快照与采集日志支持。

15 分钟快照记录停车场状态，不能追踪某位司机的停车结果或捕捉两个快照之间的全部变化。本目录的满位次数是停车场与时点观测次数，不是独立司机失败次数。
