本目录基于组内提供的 `two_year_training_corrected_proposal.csv`。时间按新加坡当地时间（UTC+8）解释。原始数据和训练代码保持原样。

- SHA-256 为 `96bd9f118a2873eb2dcddbbec02255c283a02b1002dde07ffb095434359e1b12`。
- 范围为 2024-11-05 00:00 至 2026-11-04 23:45，共 730 天、8 场、560,637 行。
- 完整 15 分钟网格应有 560,640 行。仅缺 PRM 在 2026-04-20 14:30、14:45、15:00 的三条记录，正好对应上一版容量从 576 变成 234 的三条异常。
- 键 `(timestamp_sgt, carpark_id)` 无重复。549,569 行有效，有效率 98.0258%，11,068 行无效。程序独立重建的有效标记与源文件 `valid_5min` 完全一致。

## 时间可用性与目标标签

按 CSV 给出的更新和快照时间核对，有效行中未来更新、未来快照、缺失更新时间、缺失快照时间均为 0。有效行更新年龄均在 17–300 秒内，中位数 76 秒、99 分位 128 秒。所有有效行的 `snapshot_time_sgt` 均等于决策时刻，应结合下文的来源说明理解。

程序仅用原始观测重建未来目标。15 / 30 分钟的可训练标签为 542,374 / 535,341 条，与源文件 `can_train_*` 完全一致；合格标签的占用率、空位数、真正满位和近满事件均无差异。源表自带的未来目标没有被当作预测特征。

公共假日标记与仓库的 MOM 日历逐行一致。两年合计 24 个公共假日日期，最近一年 12 个。

## 分段和分母

`quality_by_period.csv` 给出总体汇总，`quality_by_carpark.csv` 按场细分。事件率以该组有效快照数为分母，比例字段使用 0–1。满位为空位 = 0，低余位为空位 < 3，近满为空位 < 容量的 10%，后两者包含真正满位。占用率为快照算术平均。

各 period 标签的覆盖有重叠，只有同一种切分下的 train、validation、test、embargo 四组可以相加。全量、第一年和最近一年用于描述数据，不应与训练分段混合相加。

公平历史长度比较采用共同边界。验证从 2026-06-12 开始，测试从 2026-08-24 开始；两个边界前各隔离 30 分钟。最近一年组从 2025-11-05 开始，共有 219 个训练日期，两年组有 584 个训练日期。验证与测试各 73 个日期，两组完全相同。

| 对比组 / 分段 | 有效原始快照 | 公共假日日期数 |
| --- | ---: | ---: |
| 最近一年训练 | 165,170 | 10 |
| 两年共同边界训练 | 439,090 | 22 |
| 共同验证 | 55,259 | 2 |
| 共同测试 | 55,188 | 0 |

另外，完整两年按默认 60/20/20 切分，验证从 2026-01-17 开始，测试从 2026-06-12 开始。训练 / 验证 / 测试有 438 / 146 / 146 个日期，假日日期数为 14 / 8 / 2。该实验用于覆盖更长的留出期，其指标不能与 73 天共同测试结果直接作历史长度优劣归因。

此处统计的是当前快照数。未来目标评分还要求同段标签，推荐回放还要求候选集合与端点完整，因此模型、推荐的样本数会进一步减少。

## 场站差异与可追溯性

新文件的每个停车场在有效行中容量恒定，PRM 为 576。KAS 为 26，在两年数据中满位快照 30,250 次，占全部 41,656 次的约 72.62%；共同测试中为 3,036 / 3,433，约 88.44%。最近目的地的 KAM 在共同测试期仍无满位。

新文件全部 `source_path` 都写为 `api/data.gov.sg`，没有保留旧文件逐个 JSON 快照的相对路径。同时全部共同记录的快照时间都被规范为决策时刻。这里验证的是所提供 CSV 的字段和目标一致性，实际采集时刻、上游修正过程和官方来源仍需要原始 API 响应、快照文件与转换日志核实。

逐时点满位事件是停车场状态观测。当前数据无法追踪个别司机的真实停车结果，也无法观察两个 15 分钟快照之间的所有进出变化。
