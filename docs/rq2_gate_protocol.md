# RQ2 扩展：先满足余位门槛，再选最近场

记录日期：2026-11-06。本方案在本轮门槛实验结果产生前固定，是已查看旧结果后的回顾性扩展，不覆盖原 C−C0 主实验。

## 问题与假设

原评分为 w × distance/1000 + (1−w) × occupancy，标准两年选定 w=0.25。因此占用率降低 1 个百分点可抵消 30 米距离。在多个候选都很空时，规则仍奖励更低占用率，可能增加不必要距离。此前晚高峰 C 比 C0 多 12.81 / 27.50 米，未观察到满位收益。

新假设：使用绝对余位门槛后在达标候选中选择最近场，可能减少距离；预测的额外价值必须与同规则的当前状态版比较，不能把改规则的收益全部归功于预测。

## 两个对称的新策略

| 策略 | 出发时已知的余位信号 |
| --- | --- |
| CURRENT_GATE | 当前观测空位 current_lots_available |
| FORECAST_GATE | (1−M1 预测占用率) × 出发时观测容量 total_lots |

不使用未来真实容量计算预测空位，不对预测空位取整。满足估计空位 ≥ k 的候选排在前面，并按距离、停车场 ID 排序；不达标候选按估计空位降序、距离、ID 排序。若全部不达标，则选择估计空位最多的场作为兜底，仍标明没有候选满足门槛。

两个策略使用同一 k、候选集合、出发时点与到达标签，分别保留 visitor_eligible 和 open_at_departure 两种口径；扩展重点报告出发有位场景。原 A/B/C0/C、XGBoost / CatBoost 风险策略均保留，原模型和距离权重不变。

## 仅在验证段选择共享门槛

固定网格 k ∈ {1,3,5,10,20}，同一 k 用于两个策略和两个预测时长。复用 two_year_standard 的验证预测，主要口径为 open_at_departure。

对每个 k，仅看 CURRENT_GATE 在验证段的结果：15 / 30 分钟分别满足“观察到的满位率和少于 3 个空位率均不高于原 C0”，才视为可行。可行 k 中选择跨两个时长、按场景数加权的平均距离最短者；距离并列选较小 k。若无可行 k，使用预先固定的 k=3，并明确记录验证约束未满足。

上述只是验证段的观察条件，不能称为安全保证、风险上界或统计非劣性。FORECAST_GATE 和测试结果不参与 k 的选择。

## 测试与归因

使用原标准两年测试期 2026-06-12 至 2026-11-04，相同完整候选/场景。先核对旧六策略指标复现发布结果，再评价锁定的 k。全部 k 的敏感性均保存，不能根据测试结果更换主 k。

| 配对比较 | 用途 |
| --- | --- |
| FORECAST_GATE−CURRENT_GATE | 同门槛规则下预测的增量，RQ2 扩展核心 |
| CURRENT_GATE−C0 | 改变评分规则的影响 |
| FORECAST_GATE−C0 | 新预测策略相对旧基线的总变化，不单独归因于预测 |

主要结局仍是真正满位（空位=0），少于3位、比例近满（<10%空位）、距离和 Top3 可行率分别报告。记录首选改变率和兜底率。原始事件数与样本数同时展示。

按新加坡出发日期整块配对 bootstrap 10,000 次和双侧符号翻转检验，在整张配对表内做 Holm 校正，95%区间不校正。全零差异不证明等效；未显著变差也不证明非劣。块独立性、跨日相关、少量事件以及已查看测试数据是推断边界。

## 保留的研究结论边界

如果静态门槛版与预测门槛版相当，则收益主要来自决策规则；不能写成预测模型明显改善了 RQ2。如果只有距离下降，应报告距离改善及观察到的风险结果，不能换成“失败率明显降低”。本轮不继续在测试集上搜索阈值、目的地或时段。

## 第二阶段：为点估计增加经验误差余量

第一阶段已执行，预定的 5 个门槛全部未通过验证段经验约束。k=3 的诊断结果仅用于说明局限，不采用为改进策略。该结果保留，不通过提高门槛或更换测试场景来挽救它。

针对点估计没有表达不确定性这一缺陷，增加一次预先固定的新方法扩展；完成后停止在当前测试集上继续搜索方法。第二阶段参数与实现写在这里之后再执行。旧模型不重训。

### 分开估计误差和选择参数

将原验证段按时间分为两段：2026-01-17 起至 2026-04-01 前用于误差校准；2026-04-01 起至原测试边界 2026-06-12 前用于参数选择。校准决策时刻须早于 2026-04-01 减 30 分钟，所有校准目标也须早于 2026-04-01。沿用原测试前 30 分钟隔离。

校准样本必须具备同段真实标签、有效出发和有限 M1，两个信号共享样本。对每个停车场、每个时长分别计算当前空位和预测空位的高估残差：估计空位 − 真实到达空位。安全余量为该残差 q 分位数与 0 的较大值，采用 higher 经验分位数。缺少校准样本的停车场不得借测试数据补齐，直接报错。

CURRENT_BUFFERED_GATE 使用当前空位减自身校准余量；FORECAST_BUFFERED_GATE 使用 M1 预测空位减自身校准余量。结果裁剪至 0 与当前容量之间，再按第一阶段的门槛和距离规则排名。open_at_departure 仍由真实当前空位筛选，不能用减余量后的值过滤候选。

这两个规则都利用历史残差；当前版没有 M1 信号，但不是原 C0。经验余量不是概率，也不构成保守覆盖或安全保证。

### 固定网格与约束

预定 q ∈ {0.90,0.95,0.975,0.99}，k ∈ {3,5,10,20}，共 16 组。当前版与预测版共用 (q,k)，按相同 q 分别校准自身残差。

仅在后半验证段，以 CURRENT_BUFFERED_GATE 对同候选的原 C0 满位/低余位率作为经验约束，分别要求两个时长不高于 C0；可行组合中选合并平均距离最短，距离并列依次选较小 q、较小 k。不以预测版或测试结果选择。

如果没有可行组合，主运行仍保留原 C0，(0.95,3) 只作为预定诊断输出并标记不可采用。全部组合的测试敏感性保留，不能重新选最优测试组合。

三个归因对照、两种候选口径与 10,000 次配对块统计沿用第一阶段，第二阶段整张配对表单独 Holm 校正。结论明确区分原主实验、第一阶段失败诊断和第二阶段的回顾性扩展。即使观察到距离下降且未检出风险恶化，也不能宣称已证明风险非劣。
