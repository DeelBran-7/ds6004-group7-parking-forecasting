# RQ1 / RQ2 补充实验方案

方案记录日期：2026-11-06。以下设置在本次补充实验出结果前固定；原两年 60/20/20 主实验与一年/两年比较均保留。

## 为什么调整截图里的设计

原 proposal 的 RQ1 是假日特征的增量价值（M1 对 M0），RQ2 是同一排名规则下预测的增量价值（C 对 C0），RQ3 是风险与距离权衡。

当前数据覆盖 2024-11-05 至 2026-11-04，730 天内有 24 个公共假日日期、706 个非假日日期，前后一年各 12 个假日。假日口径采用仓库现有 MOM 日期表，包括表内的补假和投票日。8 个停车场不会把独立假日日期数乘以 8。

不能用“两年全部非假日训练、全部假日测试”来回答 RQ1：训练中的二元 is_holiday 恒为 0，树模型无法学到这列的假日作用；同时后期非假日会进入早期假日测试的训练集，破坏时间外推。该设计下的零收益不能证明假日效应弱。

## 实验一：覆盖完整后一年假日的时间留出

| 分段 | 决策日期范围 | 日历假日日期数 |
| --- | --- | --- |
| 训练 | 2024-11-05 至 2025-09-04 | 11 |
| 验证 | 2025-09-05 至 2025-11-04 | 1 |
| 测试 | 2025-11-05 至 2026-11-04 | 12 |

两个边界前各隔离 30 分钟；预测标签必须在连续有效段内，不插补。分段按出发时刻，假日评分按目标到达日期。训练同时包含假日与非假日。保留现有 XGBoost 特征、超参数和 200 轮设置，M1 仅比 M0 增加 is_holiday，不根据本次测试结果调参。验证段不回填训练。

只重训 M0 / M1 × 15 / 30 分钟四个模型；风险分类器和推荐不在这个新窗口重训。B0 / B1 为固定基准。

在 B0/B1/M0/M1 的共同可评分样本上输出整体、假日、非假日 MAE / RMSE，比较 M1−M0 与 M0−B0，并列出各假日的逐日误差和样本数。MAE 的 CSV 单位为占用率比例，报告图乘以 100 显示百分点。

主统计按目标日期整块重采样 10,000 次，报告未校正的 95% percentile bootstrap 区间与双侧符号翻转检验；p 值在整张配对 CSV 内做 Holm 校正。另把连续假日日期合为一个 episode，做同样的块统计敏感性分析，避免把连续假日完全视为独立；episode 仅由日历定义，不按结果合并。两个统计口径分表报告，不选择更有利的一种作结论。日期或 episode 之间的相关性仍是限制。

这是已查看数据上的回顾性补充分析，不是全新独立确认；应与原标准时间切分结果并列，最终泛化确认仍需未使用日期。

## 实验二：现有标准两年输出的固定子组

使用已完成的 two_year_standard 测试输出（2026-06-12 至 2026-11-04），不重训模型、不修改策略或验证段选定的距离权重。

| 子组 | 根据出发时刻筛选，Asia/Singapore |
| --- | --- |
| overall | 全部测试出发时刻 |
| evening_peak | 17:00 ≤ 时间 < 20:00，每天 |
| weekend | 星期六或星期日，全日 |

晚高峰和周末可以重叠，不能相加作为独立样本。先定义子组再计算，不根据实际到达满位筛选。

预测：报告共同样本 MAE / RMSE、样本数与日期数；配对比较 M0−B0 和 M1−M0。推荐：分别报告 visitor_eligible 与 open_at_departure，在同一组出发时点上比较 A/B/C0/C 和两种直接风险策略，保留真正满位（空位 = 0）为主要结果，少于 3 个空位和比例近满（<10% 空位）为独立次要结果，距离为直线距离。

推荐配对比较 C−C0、XGBoost risk−C0、CatBoost risk−C0，报告首选改变次数。统计按出发日期整块重采样 10,000 次，分别在预测与推荐的整张配对表中做 Holm 校正；区间不做多重校正。

不得预先写“高峰 / 周末改善更大”。分层点估计只描述观察结果，除非额外做正式的交互检验，否则不能声称子组间增益存在统计显著差异；所有子组及不利结果均保留。子组和主要结局不因结果变更。
